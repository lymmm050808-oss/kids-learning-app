# 演示检查清单

## 演示前

- 确认使用 HTTPS 正式网址，并且打开后要求家长登录。
- 使用虚构测试账号和虚构学习数据；演示账号不要和真实家长账号共用。
- 手机浏览首页、完成一道语文题和一道数学/英语题，再打开家长中心。
- 检查按钮、文字、题目选项在手机窄屏上没有被裁切；确认软键盘弹出时搜索框仍能使用。
- 在家长中心试搜“孩子不喜欢看书怎么办”，确认结果显示资料来源；再搜一个未收录问题，确认页面提示没有匹配内容。
- 如需演示安装，在 Android Chrome 使用“安装应用”；在 iPhone 使用 Safari 的“添加到主屏幕”。

## 截图/录屏建议

1. 儿童首页：显示三科入口、当天探索进度和知识星球主题。
2. 答题过程：显示题目、选择答案和摘星反馈，不展示账号信息。
3. 家长中心：展示可调整的题量/时长、学习概览和资料检索。
4. 手机主屏幕：可选，展示安装后的应用图标与独立窗口。

## 隐私检查

- 裁掉浏览器地址栏中的个人标识、邮箱、Supabase 项目后台和开发者工具。
- 不展示真实儿童姓名、年龄、答题历史、邮件、密码、访问令牌或密钥。
- 若没有独立的虚构测试数据，宁可只录页面交互，不展示学习记录数字。
