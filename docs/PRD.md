# 幼儿启蒙 · 知识星球 产品需求文档（PRD）

- **版本：** 1.0
- **更新日期：** 2026-10-26
- **产品状态：** 个人作品集原型，持续迭代中

## 1. 产品概述

“幼儿启蒙 · 知识星球”是一款面向 3–6 岁儿童家庭的网页学习应用。孩子可以在语文、数学和英语星球完成短题目、获得星星；家长可以调整每日学习目标、查看学习记录、检索启蒙资料，并在需要时用当前设备记录一段带声音的学习视频。

产品以短时、轻松、可由家长掌控的探索体验为目标。现阶段是个人使用的 Web/PWA 原型，不是已上架的原生手机应用。

## 2. 用户与使用场景

### 主要用户

- **儿童（3–6 岁）：** 在家长陪伴下完成图片识字、数感与简单运算、生活英语等启蒙题目。
- **家长：** 管理学习目标与账号数据，查看进度、查找启蒙资料，并决定是否录制和保存学习片段。

### 核心场景

1. 家长登录后，孩子从首页进入一个知识星球并完成一组题目。
2. 家长查看当天各科答题数和用时，按孩子情况调整目标。
3. 家长在陪伴学习时，主动开启本次摄像头和麦克风录像，结束后预览并下载视频。

## 3. 产品目标与非目标

### 目标

- 提供清楚、可操作、适合亲子陪伴的三科启蒙答题流程。
- 让家长可以调整每日学习量和时间提醒，并查看学习记录。
- 让录像由家长主动开启、明确控制和保存，默认不采集、不上传。
- 为后续 HTTPS 部署、手机体验和作品集展示建立可说明的产品基线。

### 当前不包含

- 生成式 AI 问答、付费模型调用或本地大模型。
- 向量数据库或语义检索。资料区目前是带来源的关键词匹配。
- 自动上传、云端存储或云端分享学习录像。
- 离线答题和离线数据同步。
- 应用商店上架与原生 iOS/Android 客户端。

## 4. 功能需求

### 4.1 儿童首页与知识星球

- 首页提供语文、数学、英语三个科目入口，并显示累计星星和今日探索记录。
- 题库按 3–4 岁、5–6 岁分层；当前每科每年龄段包含 50 道题。
- 每次进入科目任务完成 5 道题；答对获得星星，页面显示答题反馈。
- 题目可通过“听一听”进行语音朗读。

### 4.2 每日目标与休息提醒

- 家长可设置每天每科目标：5、10、15 或 20 题。
- 家长可设置每日时长提醒：10、15、20 或 30 分钟。
- 任一目标达到时，向家长/儿童显示温和休息提醒；不锁定页面、不阻止继续学习。
- 每日记录按日期展示；当天已提示后不重复弹出，新的自然日开始后显示新一天的记录。

### 4.3 家长中心与学习记录

- 家长可查看今日各科答对情况、学习时长和最近 7 天概览。
- 学习设置、答题记录等云端数据由 Supabase 保存，并通过账号与 RLS 限定家庭访问范围。
- 答题正确答案由数据库端受控 RPC 核对；匿名或其他家庭用户不能读取家庭学习记录和正确答案。

### 4.4 家长资料检索

- 家长可按关键词查找启蒙资料摘要和来源链接。
- 当前资料集为 24 条本地整理内容，使用关键词匹配并显示出处。
- 无匹配结果时明确提示；不调用生成式 AI，也不声称支持任意问题回答。

### 4.5 本次学习录像（新增）

- 录像默认关闭；只有家长在家长中心勾选“允许本次学习录像”后，答题页才出现录像控件。
- 家长在答题页点击“开始录像”后，浏览器才请求摄像头和麦克风权限；是否授权由家长在浏览器权限提示中决定。
- 授权后使用当前设备摄像头和麦克风记录带声音的视频；页面提供实时预览、录制时长、停止、回放、下载和删除操作。
- 视频片段只保存在当前页面运行期间的内存中，不上传 Supabase，不写入云端数据库。
- 家长点击“下载到本机”后自行保存文件。未下载片段在离开任务、返回首页或刷新页面时清除；录像开关也会复位。
- 切换或离开页面前若有未下载片段，需提示家长确认，以减少意外丢失。
- 部署网页使用摄像头/麦克风时需要 HTTPS；本机开发预览可使用浏览器允许的本地安全地址。

## 5. 核心验收标准

1. 首页能进入语文、数学、英语任一科目，并完成 5 题任务。
2. 答题反馈、星星累计和今日答题记录按实际作答更新。
3. 家长可调整题量和时长；达到目标时提醒但仍能继续答题。
4. 家长可查看最近 7 天学习概览，数据只属于已登录的家庭账号。
5. 家长资料搜索能显示匹配摘要和来源；无匹配时展示清楚的空结果提示。
6. 录像默认不可用；家长开启后才显示入口。
7. 点击开始录像前不申请设备权限；点击开始后同时请求视频和音频权限。
8. 录像停止后可预览并下载带声音视频；删除操作要求确认。
9. 录像过程中页面显示录制状态；未下载录像离开或刷新前有提示。
10. 录像文件不通过应用代码发送到 Supabase；家长关闭或离开本次学习后权限开关复位。

## 6. 隐私、安全与未成年人保护

- 录像涉及儿童影像和声音，默认关闭并由家长主动开启；不在未取得浏览器授权时访问设备。
- 录像不上传至应用后端；下载后由家长负责选择保存位置和后续分享。
- 不在公开截图、录屏或演示数据中展示儿童姓名、真实学习记录、账号邮箱、密码、访问令牌或密钥。
- Supabase 前端仅使用 Publishable key；`service_role`/secret key 不得进入前端代码或公开仓库。
- 正式公开演示使用虚构账号和虚构儿童数据，并先验证 RLS、RPC 和登录流程。

## 7. 技术方案与当前边界

- **前端：** React、TypeScript、Vite；PWA manifest 和 Service Worker 支持安装入口及有限静态资源缓存。
- **认证/数据/API：** Supabase Auth、Postgres、RLS 与数据库 RPC；目前没有独立 Node/Express 后端。
- **录像：** 浏览器 `getUserMedia` 与 `MediaRecorder`，文件暂存于当前页面。
- **资料检索：** 浏览器端关键词搜索本地资料摘要；非 RAG、非向量搜索、非生成式回答。
- **发布：** GitHub 仓库公开不等同于网站已部署。正式 HTTPS 网址、移动设备兼容、线上登录与数据权限仍需独立验证。
- **安装：** PWA 安装需要 HTTPS；当前静态缓存不代表应用可以离线完成答题或同步数据。

## 8. 后续待办

- 完成 HTTPS 私人部署，并核实访问控制与家长登录行为。
- 使用虚构账号检查不同家庭的数据隔离与数据库 RPC 权限。
- 在手机和平板上核对排版、相机/麦克风授权流程、视频预览和下载格式。
- 由家长实际测试长短片段和不同浏览器的录制兼容性；当前未录制真实儿童内容。
- 建立虚构演示数据，更新截图和作品集说明。
